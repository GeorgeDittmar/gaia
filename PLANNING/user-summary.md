# User Summary Feature — Implementation Plan

## Goal
A persistent `user_summary.md` file that the agent reads at session start to know who the user is. It dynamically updates as new information is learned, enabling natural continuity across sessions.

## Design Decisions
- **Storage:** Standalone file at `~/.gaia/user_summary.md` (human-editable markdown)
- **Logic:** Lives in the `Gaia` agent class (prepends summary to system prompt)
- **Triggers:** Periodic generation every N turns + `/summary` slash command

## File Format

```markdown
---
version: 1
last_updated: "2025-07-23T12:00:00"
facts_count: 12
conversation_count: 5
---

# User Summary

## Identity
- **Name:** George
- **Location:** (unknown)

## Preferences
- (none yet)

## Active Projects
- (none yet)

## Context
- Last interacted about: (nothing yet)

---
*Auto-generated by G.A.I.A. — updated periodically as new information is learned.*
```

## Changes

### 1. `src/gaia/core/agent/base.py` — Core logic

**New constant:**
```python
_USER_SUMMARY_PATH = Path.home() / ".gaia" / "user_summary.md"
```

**New method: `load_user_summary() -> str`**
- Reads `~/.gaia/user_summary.md` if it exists
- Returns the file content (or empty string if missing/new)
- Parses frontmatter to extract metadata

**New method: `generate_user_summary() -> str`**
- Queries episodic memory for recent planner notes (last 20)
- Queries semantic memory for top facts
- If an existing summary exists, passes it for incremental update
- Uses the extraction agent (same pattern as `post_turn_extract`) to produce a new structured summary
- Writes the result to `~/.gaia/user_summary.md`
- Returns the new summary text

**New method: `save_user_summary(text: str) -> None`**
- Writes the summary markdown to the file with frontmatter metadata

**Modify `Gaia.__init__`:**
- Call `load_user_summary()` after initialization
- Prepend the summary to the system prompt instructions
- Store as `self.__user_summary: str`

**Modify `Gaia.reconfigure`:**
- Preserve `__user_summary` (don't reset it on reconfigure)

### 2. `src/gaia/gaia_tui_app.py` — TUI integration

**New constant:**
```python
_SUMMARIZE_EVERY_N_TURNS = 5
```

**New method: `_run_periodic_summary()` (similar to `_run_periodic_extraction`)**
- `@work(exclusive=False, thread=False)` decorator
- Calls `agent.generate_user_summary()`
- Logs result

**Modify `on_input_submitted`:**
- After turn tracking and extraction check, also check if `_turn_count % _SUMMARIZE_EVERY_N_TURNS == 0`
- Call `_run_periodic_summary()`

**Modify `on_input_submitted`:**
- On first turn (turn_count == 1), trigger initial summary generation if no summary exists

### 3. `src/gaia/slash_commands.py` — `/summary` command

Add handler for `case "summary":`:
- If no memory: show message that memory is unavailable
- If memory exists:
  1. Read current `~/.gaia/user_summary.md`
  2. Display it in chat as a `ChatTurn`
  3. If file doesn't exist yet: offer to generate one

### 4. `src/gaia/config.py` — Config update

Add to `SLASH_COMMANDS`:
```python
{"cmd": "/summary", "desc": "View the current user summary"},
```
